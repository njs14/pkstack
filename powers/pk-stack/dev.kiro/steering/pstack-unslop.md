# PK-Stack prose discipline

For prose you write or edit, preserve facts, commitments, caveats, the intended
audience, and the author's recognizable voice. State concrete behavior instead
of praising it. Name sources instead of using vague attribution. Cut generic
scene-setting, repetitive summaries, canned transitions, chatbot pleasantries,
sycophancy, puffery, promotional adjectives, decorative headings, and filler.

Prefer plain verbs and specific nouns. Vary sentence length naturally. Split a
sentence when the reader must backtrack. Do not manufacture certainty,
opinions, quotations, or evidence to make the text sound more human. Flag an
unclear factual claim instead of smoothing it into an invention.

Use the `unslop` skill for a deliberate full editing and self-audit pass.
