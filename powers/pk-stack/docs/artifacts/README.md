# Architecture artifacts

This directory contains the interactive PK-Stack system diagram and its
reviewable Archify source specification.

- [`pk-stack-architecture.html`](pk-stack-architecture.html) is a self-contained
  browser artifact with guided views, light and dark themes, zoom, presentation
  mode, and export controls.
- [`pk-stack-architecture.json`](pk-stack-architecture.json) is the source used
  to validate and regenerate the HTML artifact.

The diagram is documentation, not runtime code or release evidence. It reflects
the repository architecture at commit
`2004892e7deb52cedc0063e39d84c1acbe38d95f` and cites its source files directly.
