# Apply engineering principles

Treat the request text that activated this skill as the decision or work item to assess.

Read [the principle catalog](references/catalog.md). Select only the principles whose trigger
matches the concrete decision. State each selected principle in plain language, apply its test to
the actual artifact, and resolve conflicts by preserving safety, user intent, and executable
evidence. Principles guide judgment; they do not authorize destructive, public, paid, privileged,
or out-of-scope action.

Prefer one strong principle over a pile of labels. Finish by naming the changed decision and the
evidence that shows the principle improved the result.
