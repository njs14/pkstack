# Keep reversible work moving

Treat the request text that activated this skill as the scope and authority boundary.

Apply [never block on the human](../principles/references/catalog.md#never-block-on-the-human).
Proceed on reversible work the request already authorizes and make assumptions visible. Stop when
missing intent changes the result or an action is destructive, irreversible, public, paid,
privileged, or account-level without exact authorization. Return the assumption or the precise
authority needed.
