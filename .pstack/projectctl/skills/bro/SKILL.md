# Say it plainly

Treat the request text that activated this skill as a request to simplify the immediately preceding
answer.

Lead with the practical answer. Replace jargon with ordinary words, shorten nested explanations,
and use one small example when it makes the point concrete. Keep any safety limit, uncertainty,
failure, or decision the user still needs to make. Do not add new research, pretend away a caveat,
or turn the response into a tutorial unless asked.
