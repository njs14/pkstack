# Historical pre-v0.2 evidence

This directory is reserved for evidence collected before the PK-Stack 0.2.0
release line. Records here are retained for provenance and regression context;
they are not evidence that `v0.2.0` is accepted. Each record must keep its
observed commit, runtime, source identity, and limitations intact.

The current release surface is [`../../release-status.md`](../../release-status.md).
The Floci application and live campaigns are outside this repository in the
private [pk-stack-floci-lab](https://github.com/njs14/pk-stack-floci-lab)
repository.
